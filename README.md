# 티켓팅 프로젝트
## 사용 기술
- Language : Java 17
- Framework : Spring Boot 4.1.1
- DB : postgreSQL 16
- ORM : Spring Data JPA
- Build : gradle
- Infra : 개인 Linux Server 에서 테스트 후 AWS 로 이동 예정
